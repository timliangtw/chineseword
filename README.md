# 字字小宇宙

給平板使用的字音字形複習網站。靜態 HTML / CSS / ES modules，部署至 GitHub Pages，不需要帳號或資料庫。

## 使用

正式網址：https://timliangtw.github.io/chineseword/

- iPad 用 Safari 開啟後，可從「分享 → 加入主畫面」建立入口。
- 固定用同一台裝置、同一個瀏覽器或主畫面入口；進度保存在該入口的本機儲存。
- 每回合 10 題（家長設定可改 20 題），可紙筆作答或啟用平板手寫板。
- 先作答，再翻面核對。評分按自己剛才的答案選，不會自動辨識手寫。
- 「休息一下」保留未完成回合；重新整理後首頁提供接續。
- 模擬考 20 題，全部作答後逐題核對；有手寫時可查看自己寫的答案。
- 家長設定支援大字／特大字、字形／字音範圍、考試日期、搜尋題庫、進度匯出／匯入。
- 先「下載離線題庫」，下載完成後可離線使用原網址。網站資料被清除時，本機進度及離線快取也可能被清除，請定期匯出進度。

## 排程

- 答錯約 5 分鐘後再考；回合內若還有至少 3 題，可隔題再考一次。
- 猶豫約 12 小時後再考；獨立答對依不同日期的成功次數安排 1 / 3 / 5 天。
- 同一天答對多次僅算一個成功日期。不同日期答對至少兩次才標為「記牢」；再次答錯會重新確認。
- 每天依未練題量、當天已練新題數、考前剩餘天數，重新建議新題量。目標為考前保留三整天複習。
- 每回合有到期題和新題；大量逾期題不會讓新題永遠輪不到。多做沒有每日上限。
- 已評分題目立即保存；未評分不會被當成學會。換範圍或改日期不會刪除學習記錄。

## 教材與去重

六張原始掃描題，共 600 題，去除 67 題重複後保留 533 題（字形 267 題、字音 266 題）。人工核對各題完整詞語、目標位置與注音。`data/source-metadata.json` 保留全部來源；`data/deduplication.json` 列去重結果。

以「題型＋完整詞語＋目標國字＋目標位置」合併完全重複題。不同詞語、不同考點分開保留。原稿保存在各卡片的「看看教材原題」。

原始整份掃描 PDF、暫存裁圖不納入 Git。題庫只發布本網站所需的題目片段。

## 開發與驗證

需要 Node.js 及 Python 3；網站沒有 npm 依賴。

```sh
npm start
npm test
```

`npm test` 檢查來源涵蓋、去重、資產、不同日記憶判定，以及少做、多做、漏一天、逾期與新題公平排程。

題庫重建工具：`scripts/build_deck.py`，需要 Pillow / NumPy 與 `tmp/pdfs/` 下的核對 metadata、高解析掃描。最終題庫已包含在儲存庫，可直接部署，不需重建。

本機儲存使用 `chineseword.progress.v1` 與 `chineseword.session.v1`。資料不傳至伺服器；主機僅提供網站檔案。
